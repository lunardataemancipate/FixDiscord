> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерское ПО. В результате файл удаляется и отправляется в карантин. В таком случае детект обычно называется `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройки исключений, предпочтительнее добавить исключение; при сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Его отключение способно помешать настройке и работе Secure DNS на компьютере

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/lunardataemancipate/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не нужен

4. Извлеките архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий скрипт
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — установка службы в автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить любую стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включить или отключить обход для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  После изменения параметра **нужно перезапустить стратегию**.  
  В скобках показывается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Это полезно при проверке ресурсов, которые без zapret работают, а с ним — нет.  
  В скобках отображается текущий режим:
    - `none` — проверка не применяется ни к одному IP
    - `loaded` — IP сопоставляются со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить выбранный активный фейк другим из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент
  - **`Run Tests`** — проверить стратегии:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` не видно никакого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен открыться winws.exe, отвечающий за обход. Его можно увидеть на панели задач.  
Если процесса нет, обратитесь к [#522](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Откройте текстовый редактор от имени администратора и найдите `hosts` в созданной папке
  - Вставьте скопированное в конец файла `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. При неудаче убедитесь, что сохранение действительно выполнено.

#### Результат не гарантирован. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/lunardataemancipate/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии способны со временем терять работоспособность.**
> Вначале конкретная стратегия может помогать, но после обнаружения её параметры перестают работать.
> В проекте собрано много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результат `service.bat` -> `Run Diagnostics` и исправьте найденные ошибки

- Удостоверьтесь, что нужный адрес присутствует в списках доменов или IP

- Испытайте другие варианты, включая (**`ALT`** и **`FAKE`**)

- При необходимости выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и другие данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; устраните ошибки и в конце ответьте Y
- Удалите каталог zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/lunardataemancipate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если внизу справа есть "Разблокировать", установите флажок, нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- Запускайте разные `general`-скрипты и проверяйте сайты. Если соединение не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать
- См. также [#251](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord
- Проверьте, заработало ли приложение после очистки
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей
- Если Discord не открывается и в браузере, последовательно попробуйте остальные стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/lunardataemancipate/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- обновите ipset через `service.bat` и включите `Game Filter`
- если результата нет, дополнительно активируйте `ipset any`

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если это не решит проблему, создайте обсуждение в [Discussions](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/lunardataemancipate/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены включаются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` либо `service.bat`
